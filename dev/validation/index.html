Validation

Two checks back the atlas: the population simulation layer was compared with an established open-source tool, and every model was implemented a second time from its paper alone, with separate code, and compared with the atlas implementation. Both checks were made within this project; none has yet been made by outside people.

Simulation layer against mrgsolve

The dosing and population machinery was run against mrgsolve 2.0.1 (R) on identical models, doses and time grids, with tight solver tolerances on both sides (2026-11-04). The scripts are in validation/mrgsolve/.

For the population case both tools were also compared with a near-exact reference (closed form, 4 million draws). QSPAtlas sampling with one million draws matches the reference to 1.7e-3 (largest z-score 1.96).

Differences in convention, documented in Population simulation:

  • Where steady state starts. QSPAtlas iterates dosing cycles from the model's initial conditions, mrgsolve from the state at the steady-state record, NONMEM from zero. All three agree when the iteration converges; they differ only for models with several periodic solutions or slow, history-dependent states.
  • Observations at a dose time see the state after the dose (mrgsolve recsort = 3).
  • A reset cancels lagged doses that have not yet been given and keeps later addl doses.

Third implementation from the authors' own code

For four models the authors published their NONMEM or Monolix code. That code was translated to rxode2 (R) with nonmem2rx and monolix2rx (or by hand where the code is printed in a PDF), run with the parameter values and inputs the atlas uses (the code often carries initial estimates, so this checks equations, structure, dosing and units, not the values), and compared point by point with the atlas. Scripts: validation/authors_code/.

Differences between the code and the paper that this check exposed (none affects an atlas target): in Ouerdani's code a control run (DOSE = 0) switches all drug terms off, while the paper's Eq. 2 with beta_alpha = 0 keeps alpha = alpha0 for any exposure; in Hutchinson's code the normalisation factor is N = Nmax x dose + 1, not Eq. 5's Nmax; Hutchinson's Figure 6 chemotherapy is not in the code. Stroh and Fornari published no runnable code (Stroh's supplement has the reaction matrices, checked entry by entry; Fornari's code is truncated).

Second implementations of the six models

Each model was implemented a second time from its paper and supplement alone, without access to the atlas code, in plain OrdinaryDiffEq without ModelingToolkit, within this project. The second implementation made its own choices for every unstated input. It compared simulations only: nothing was re-digitised, so digitising errors are not covered by this check. Where both implementations chose an unstated input (a dose group, a starting value) by matching the figure, their agreement is not independent evidence for that choice. Results:

No transcription error was found in any atlas model. One second implementation (Fornari) changed the reading of a units question that decides a figure grade; see that model's page.
