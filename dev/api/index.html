QSPAtlas — Module
QSPAtlas

Reproduce, score and benchmark published PK/PD and QSP models.

Each model lives in models/<author_year>/ and is reproduced by its reproduce.jl, which compares simulations against points digitised from the paper's figures and grades the result A-D (see grade).

QSPAtlas.Axis — Type
Axis(label, unit, scale, lo, hi)

One plot axis of a published figure. scale is :linear or :log; lo and hi are the axis limits as drawn in the figure. They set the scale used for comparison, so an error of 0.01 means one percent of the drawn axis.

QSPAtlas.ReferenceCurve — Type
ReferenceCurve

Points digitised from one curve of one published figure panel.

Fields: id (unique within the model, e.g. fig4_left_vehicle_P), figure (human description, e.g. "Figure 4 left, vehicle, tumour volume P"), x, y, xaxis, yaxis (Axis), kind (:curve for a line drawn by the authors' simulation, :points for plotted observations, :bars for bar heights or reported single values at category positions, :band for a shaded interval such as the authors' simulated 5th to 95th percentile band), meta (all other header keys, for example source and method), and ylo, yhi (lower and upper edge at each x; only for :band, empty otherwise). For a band, y is the midpoint (ylo + yhi) / 2, which is only used for plotting and the point count.

The eight-argument constructor (without ylo, yhi) is kept for every other kind.

QSPAtlas.Tolerance — Type
Tolerance(; rms = 0.015, p95 = 0.03)

Pass rule for one curve. Errors are distances in the figure's own axis box, where both axes are scaled to [0, 1] (log axes in decades). rms bounds the root mean square distance over all reference points and p95 bounds the 95th percentile, so one badly traced point cannot fail a curve on its own. The maximum is still reported.

The defaults allow for digitising error: published figures are about 500-700 px wide, so one pixel is roughly 0.3-0.5 % of a plot panel's axis, and a 1-2 px line plus JPEG blur puts honest digitising error near 1 %. Tolerances are frozen in each model's protocol.jl before its simulations are compared.

QSPAtlas.compare_curve — Function
compare_curve(ref, xs, ys; tolerance = Tolerance()) -> CurveComparison

Compare a simulated curve (xs, ys) against ref.

For kind = :curve references (lines drawn by the authors' own simulation), each reference point's error is its shortest distance to the simulated polyline in the normalised axis box. Using distance-to-curve instead of vertical error keeps steep sections (dose spikes, rapid expansion) from being punished for tiny horizontal digitising error.

For kind = :points references (observed data), the same distance is used; the tolerance should then be loosened by the caller, since a typical-value curve is not expected to pass through every observation.

For kind = :bars references (bar charts, tornado plots, single reported values), x is a category position, not a continuous coordinate. The simulation must supply a value at exactly each reference x (matched within 1e-9), and the error is the vertical distance only, so a bar can never be matched by a neighbouring bar. A missing or non-finite simulated bar counts as the maximum error (1.0), never as a pass.

For kind = :band references (a shaded interval, e.g. the authors' simulated percentile band) and for kind = :curve references with the header # metric: vertical (stored as meta["metric"]; percentile lines of a population simulation) the comparison is VERTICAL at the reference x, not by nearest-polyline distance. The simulated curve is evaluated at each reference x: a finite simulated point at exactly that x (within 1e-9 of the normalised axis) is used as it is, otherwise the value is interpolated between the two neighbouring finite points, linearly in the displayed coordinates (decades on a log axis, x and y). Only then is the error taken: for a band 0 inside [ylo, yhi] (edges inside) and else the distance to the nearest edge, for a vertical line the distance to the reference y, in normalised axis units, capped at 1. A reference x outside the simulated range, or in a gap of non-finite simulated points (gaps are never bridged), counts as the maximum error 1.0. Simulated x must be sorted; one finite point is enough when it matches. For a band the default Tolerance is the allowance for digitising its edges.

Simulated values are clipped to the axis box plus a margin of one box, so a simulation that leaves the figure is scored as far off rather than infinitely off.

QSPAtlas.Fix — Type
Fix(id, kind, description; evidence = "")

A documented change needed to make a model match its paper. kind is one of :typo (equation or value misprinted), :missing (value or rule not stated and inferred), :units (unit inconsistency), :ambiguity (text allows several readings; the one used is stated), :code (taken from supplementary code where the text differs), or :from_target (an unstated input read from, or chosen by matching, the very figure being reproduced). evidence says where the fix comes from (supplement file, equation number, figure) so a reader can check it; a fix without evidence cannot earn a B.

:from_target fixes are circular for the values they set: a grade that depends on one is marked with a dagger (B†) and score.toml records inputs_from_target = true. Only use it for protocol inputs (initial conditions, which of several published scenarios a figure shows), never for model parameters; a model whose parameters must be read off its own figure is D.

QSPAtlas.grade — Function
grade(r::Reproduction) -> Char
  • 'A': the model as published runs and matches every reference curve.
  • 'B': it matches only after the documented fixes, each with evidence.
  • 'C': it runs but does not match, with or without fixes.
  • 'D': it cannot be run from published information (blocker set, or no run completed).

Recalibration never changes the grade: grades describe the published model, and refitted results are reported separately.

QSPAtlas.benchmark_problem — Function
benchmark_problem(setup, solvers; reference_alg = nothing, reference = nothing, abstols, reltols, numruns = 10, kwargs...)

Work-precision set for one model problem. Solves a reference with reference_alg at abstol = reltol = 1e-12 (or uses reference, a solution computed that way beforehand), then times every solver in solvers (DiffEqDevTools format, e.g. [Dict(:alg => Tsit5())]) across the tolerance grid.

Error is the dense L2 error (error_estimate = :L2, dense_errors = true): both solutions are compared through their interpolants over the whole time span. Sparse errors at saved points are wrong for dosed models, because a dosing callback saves each dose time twice (before and after the jump) and the comparison then measures the dose size instead of the solver error. saveat is therefore not passed to the timed solves; timings include dense output.

QSPAtlas.Route — Type
Route(cmt, state; rate = nothing, scale = 1.0)

Map a dose compartment name cmt to the model. state is the unknown of the compiled system that receives bolus amounts (for example sys.A1). rate is the declared parameter that receives infusion rates, used in the model as D(A1) ~ ... + Rin; leave it nothing for bolus-only routes. scale converts dose units to model units: model amount = scale * dose amount.

source
QSPAtlas.Dose — Type
Dose(time, amt; cmt, rate = 0.0, duration = 0.0, ss = false, ii = 0.0)

One dosing event as entered. With rate = duration = 0 it is a bolus. Give rate for a zero-order infusion of fixed rate (duration = amt / rate), or duration for an infusion of fixed duration (rate = amt / duration). If both are given they must agree. amt must be non-negative; a zero amount is kept as a zero bolus.

The field fixed records which of the two was entered (:rate, :duration, or :none for a bolus), because bioavailability acts differently on each (see DoseControl).

ss = true (NONMEM SS=1) says the subject is at steady state on this dose repeated every ii when it is given; see Regimen. It needs ii > 0 and amt > 0. For a non-steady-state dose ii is ignored and stored as 0.

source
QSPAtlas.Regimen — Type
Regimen(amt; time = 0.0, cmt, ii = 0.0, addl = 0, rate = 0.0, duration = 0.0, ss = false, reset = false)
Regimen(r1, r2, ...)       # Regimens and Resets
vcat(r1, r2, ...)

NONMEM-style dose record: amt at time, then addl more doses every ii. rate and duration make it an infusion, see Dose. Several regimens combine into one, sorted by dose time (doses at equal times keep their order). Get the dose list with doses.

  • ss = true (NONMEM SS=1, needs ii > 0): the FIRST dose of the record is a steady-state dose. The subject is taken to have received this dose every ii for a very long time (the state at time is the periodic state of the cycle simulated from the initial conditions), including lagged doses and infusions that are still running; the addl doses then follow as ordinary doses. A regimen can hold several steady-state doses only if they share time and ii. The record resets the state at time (see below); everything the regimen did before time is superseded at time.
  • reset = true (EVID=4, reset and dose): a Reset at time, then the doses. Regimen(Reset(t)) is a pure reset (EVID=3), also usable inside Regimen(r1, Reset(t), r2).
  • A reset at the time of a dose applies BEFORE that dose, and the dose (with its lag) is kept. A reset cancels doses given before it that have not entered the model yet (lag lands at or after the reset time) and stops infusions that are running (the rest of their amount is never given). Steady-state doses are not allowed to combine with reset = true.
source
QSPAtlas.DoseControl — Type
DoseControl(; bioav = Dict(), lag = Dict())

Subject-specific dose control, per compartment name (Dict(:depot => 0.8)). Missing entries mean bioav = 1, lag = 0.

  • bioav (F): scales bolus amounts. For an infusion entered with a rate, F scales the duration and keeps the rate (NONMEM and Pumas convention). For an infusion entered with a duration, F scales the rate and keeps the duration. Either way the infused amount is F * amt.
  • lag: delays the start of every dose in that compartment (an infusion keeps its length).
source
QSPAtlas.DoseEvent — Type
DoseEvent(time, kind, cmt, amount, rate)

One resolved solver event: kind is :bolus, :infusion_start or :infusion_stop. Times are after lag; amount (bolus) and rate (infusion) are in model units, after F and the route scale. Infusion events have amount = 0, bolus events rate = 0.

Two more kinds set the whole state (cmt is :all, amount and rate are 0): :reset sets every state back to its value when the solve started (the initial conditions), and :steady_state sets every state to the vector in the sixth field state (the steady state; resolve leaves it nothing and the simulation fills it in per subject). The state is set first, then the other events of the same time apply on top of it.

QSPAtlas.resolve — Function
resolve(regimen, routes, control = DoseControl()) -> Vector{DoseEvent}

Turn a regimen into the events the solver needs, for one subject: lag shifts every start, bioavailability scales amounts (see DoseControl), the route scale converts to model units, and an infusion becomes a start and a stop event. The result is sorted by time. At the same time infusion stops come first, then infusion starts, then boluses; all boluses at one time are kept (they add up). An infusion whose stop time equals its start time in floating point (duration lost next to the dose time) is an error, not silently dropped.

Resets (Reset, reset = true) become :reset events, sorted before all other events of the same time. A dose is cancelled if a reset comes after the time it was GIVEN but not after it ENTERS the model: a bolus (or infusion start) whose lagged time is at or after the first reset later than the dose time is dropped; an infusion that is running at that reset is stopped there. A dose given at the reset time itself is after the reset and kept.

A steady-state dose (ss = true) becomes a :steady_state event at its time (state still nothing: it depends on the model and the subject, see simulate), which acts as a reset at that time for everything given before. For the doses of the periodic history that are still pending at that time it adds the events they cause from there on: boluses whose lagged time is at or after the steady-state time, and infusions that are still running (switched on at the steady-state time, stopped at their original stop time). Those carried events follow the same rules for later resets as ordinary doses.

source
QSPAtlas.dosing_callback — Function
dosing_callback(sys, events, routes) -> (callback, tstops)

Callback for an ODEProblem built from the compiled system sys, applying the resolved events. A bolus adds its amount to the route's state. For infusions the route's rate parameter is set at every start or stop to baseline + sum of the rates of the infusions running now, recomputed from scratch, where baseline is the parameter value found when the solve started. So overlapping infusions sum, there is no accumulated rounding, and the parameter is restored to the baseline exactly when the solve ends (also mid-infusion), which leaves sol.prob as found. The per-solve baseline is kept per integrator, so one callback object can be used by many solves at once (for example EnsembleThreads) and for different tspans.

:reset and :steady_state events set all states (in the order of unknowns(sys)) before the other events of their time: a reset to the state the solve started with, a steady state to the vector stored in the event. They do nothing about infusions or pending doses: those are cancelled when the events are produced by resolve.

Events are grouped only when their times are exactly equal; times a rounding error apart stay separate events. An infusion is on for start <= t < stop. Events at the initial time are applied before the first step; events before it are ignored, except that an infusion already running at the initial time is on. Events after the end of tspan are never reached; an event exactly at the end fires. Pass callback (and tstops) to ODEProblem or solve. tstops lists the event times; the callback schedules them too.

QSPAtlas.SteadyStateOptions — Type
SteadyStateOptions(; rtol = 1e-8, atol = 1e-10, maxcycles = 1000, allow_time_dependent = false)

Convergence control for steady-state doses (ss = true). The state at the start of a dosing interval is found by simulating cycle after cycle (length ii, same model, parameters, F and lag) from the initial conditions. It has converged when, for EVERY state, the change over a cycle is at most atol + rtol * |x| (compared directly, so a state that stays exactly 0 is fine even with atol = 0). After maxcycles cycles without convergence, or if the state becomes non-finite or the solver fails in a cycle, SteadyStateError is thrown; a non-converged state is never used. The change over one cycle underestimates the distance to the steady state by about 1 / (1 - r) where r is the per-cycle contraction factor (a state that decays slowly compared to ii needs a tighter rtol or a higher maxcycles).

The cycle iteration restarts every cycle at the same absolute time T, so it is only valid for AUTONOMOUS dynamics (plus the dosing). If the compiled system depends explicitly on time (an exp(-δ t) or sin(t) in an equation or observed expression), a steady-state dose is refused with an ArgumentError. allow_time_dependent = true overrides that: the user asserts that the forcing is periodic with period ii (or a divisor of it) and phase-aligned with T.

QSPAtlas.ErrorModel — Type
ErrorModel

Residual error model for one observed endpoint. sample_dv(err, ipred, rng) draws one observation given the individual prediction, always consuming exactly one standard normal draw from rng (also when σ = 0, or ipred is NaN), so that the stream stays aligned. sd(err, ipred) is the standard deviation of that observation given ipred.

  • AdditiveError(σ): dv = ipred + σ ε
  • ProportionalError(σ): dv = ipred (1 + σ ε)
  • CombinedError(σadd, σprop): dv = ipred + sqrt(σadd² + (σprop ipred)²) ε
  • ExponentialError(σ): dv = ipred exp(σ ε); median-centred (median dv = ipred, the mean is ipred exp(σ²/2)), always positive for positive ipred.

QSPAtlas.PopulationModel — Type
PopulationModel(sys; routes, θ, ηnames, Ω, params, init = (θ, η, c) -> Pair[], observed,
                error, tspan, solver, solve_kwargs = (;))

A structural model sys (compiled MTK system) with typical values θ, between-subject random effects η ~ N(0, Ω) (names ηnames, covariance Ω in that order) and residual error. Individual values come from

  • params(θ, η, covariates) -> Vector{Pair} of MTK parameter values (η and covariates are NamedTuples),
  • init(θ, η, covariates) -> Vector{Pair} of initial conditions.

observed and error are NamedTuples keyed by endpoint name: symbolic observable (state or expression) and its ErrorModel. routes map dose compartments to states (see Route); their rate parameters must not be returned by params. The final field cache holds the lazily built base problem.

Time-varying covariates re-evaluate params at each change time and set the parameters whose value changed. Initial conditions are not re-applied, and only parameters that params returns are updated.

QSPAtlas.SimResult — Type
SimResult

Output of simulate, as tidy rows.

  • obs: one row per (replicate, subject, endpoint, observation time): (replicate, id, time, endpoint, ipred, dv, retcode). ipred is the individual prediction, dv the observation with residual error (equal to ipred when residual = false). An observation at the time of a dose or covariate change sees the state AFTER that event.

QSPAtlas.simulate — Function
simulate(model, subject; η = :sample, residual = true, rng = Xoshiro(0), tspan = nothing,
         steady_state = SteadyStateOptions()) -> SimResult

Simulate one subject. η = :sample draws η ~ N(0, Ω) from rng, :zero uses η = 0 (the zero-random-effect prediction), or pass a NamedTuple / vector of η values. residual = false returns dv = ipred. The residual error uses its own stream, seeded from rng right after the η draw (so η does not depend on residual). tspan defaults to the model's, extended to the last observation time if needed.

Steady-state doses (ss = true, see Regimen) and resets are handled here: for a steady-state dose at time T the state at T is found per subject with that subject's parameters (covariates frozen at their value at T), by cycling from the subject's initial conditions as set by SteadyStateOptions; the solve then continues from that state with the infusions and pending doses of the periodic history switched on. T must not be before the start of tspan (an error); a steady-state dose after the end is ignored. If there is no steady state, SteadyStateError is thrown by this single-subject method. (In a cohort the same failure is a per-trajectory outcome, see below.) A reset sets every state to the subject's initial condition at the start of the solve.

source
simulate(model, subjects; replicates = 1, seed = 0, η = :sample, residual = true,
         ensemble = EnsembleThreads(), tspan = nothing, steady_state = SteadyStateOptions()) -> SimResult

Simulate a cohort. replicates is the number of times the whole cohort is re-simulated (new η and residual draws each time). Subject ids must be unique.

Reproducibility: every (replicate, subject id) has its own random streams, derived from seed, one for η and a separate one for the residual error. The results therefore do not depend on the number of threads, on ensemble, or on the order of subjects (the order of the output rows follows the cohort order).

A trajectory whose steady-state dose has no steady state (SteadyStateError) does not abort the cohort: it is not solved, its subject row has retcode = :SteadyStateFailed and an extra field message, its observation rows have ipred = dv = NaN and the same retcode, and the usual single warning counts it. A malformed regimen or model (steady-state dose before tspan, explicit time dependence, unknown compartment, ...) still throws for the whole call.

QSPAtlas.percentiles — Function
percentiles(r::SimResult, endpoint; q = (0.1, 0.5, 0.9), bins = :obstimes, value = :dv,
            by_replicate = false, min_n = 1, blq = nothing) -> Vector{NamedTuple}

Quantiles of one endpoint of a simulation, over subjects, per time bin.

Rows (one per bin and q, ordered by bin then q; by replicate first when by_replicate): (bin, bin_lo, bin_hi, t_mid, q, value, n, n_failed, n_blq), plus replicate first when by_replicate = true. By default the replicates are pooled, so n counts subjects times replicates.

  • value: :dv (with residual error) or :ipred.
  • bins = :obstimes: one bin per distinct observation time, matched exactly (bin_lo == bin_hi == t_mid = the time). bins = edges (a strictly increasing vector): bins [e_k, e_{k+1}), half-open, except that the last bin also contains its upper edge; observations outside the edges are ignored; t_mid is the bin centre.
  • Quantile definition: Hyndman-Fan type 7 (Statistics.quantile's default; linear interpolation between order statistics).
  • Values that are not finite (failed solves leave NaN) are excluded and counted in n_failed; one warning reports the total. A bin with fewer than min_n usable values gives value = NaN (its n is still reported). The default min_n = 1 only rejects empty bins; quantile estimates from a handful of values are poor, raise it to be strict.
  • blq = (lloq = x, handling = :censor_to_lloq | :drop | :keep): values below lloq are set to lloq (default), removed (this biases quantiles upwards), or kept; n_blq counts the values below lloq in every case, n the values that were used.

QSPAtlas.vpc — Function
vpc(model, subjects; endpoint, q = (0.1, 0.5, 0.9), bins = :obstimes, replicates = 200,
    pi_level = 0.95, seed = 0, value = :dv, blq = nothing, observed = nothing, min_n = 1,
    simulate_kwargs...) -> VPCResult
vpc(r::SimResult; endpoint, ...)

Simulation-based visual predictive check. The cohort subjects is simulated replicates times (simulate(model, subjects; replicates, seed, simulate_kwargs...), so it is reproducible from seed and independent of threads). In every replicate the q-quantile of endpoint is taken per bin over the subjects (percentiles with by_replicate: same bins, value, quantile definition, failed value handling, min_n and blq). Per bin and q the rows then give the median of those replicate quantiles, the pi_level interval across replicates (Hyndman-Fan type 7 quantiles of the K replicate values, at (1 - pi_level) / 2 and (1 + pi_level) / 2) and mc_se, the Monte Carlo standard error of that median (QSPAtlas.mc_se_median: bootstrap over the replicates, 500 resamples, generator seeded from seed and the bin, so it is reproducible and handles ties from BLQ censoring). mc_se shrinks like 1 / sqrt(replicates); the interval lo..hi does not shrink, it estimates the spread of the quantile for a cohort of this size. Only replicates with a defined quantile count (n_rep).

value = :dv includes the residual error, :ipred does not. For a population target freeze subjects, bins, value, replicates and seed before comparing with a reference, and keep mc_se small next to the tolerance.

observed is optional observed data, a vector of (id, time, dv) named tuples. It gives the observed quantiles per bin (pooled over subjects, same bins, min_n, blq), stored in VPCResult.observed. This is a diagnostic: nothing in the atlas is graded on it. With bins = :obstimes, observed times must equal simulated times exactly to be binned; the rest is counted in n_unbinned.

Failed or NaN simulated values are excluded and counted (n_failed, one warning).

QSPAtlas.VPCResult — Type
VPCResult

Result of vpc.

  • rows: one per (bin, q), ordered by bin then q: (bin, bin_lo, bin_hi, t_mid, q, median, lo, hi, mc_se, n, n_rep, n_failed, n_blq). median is the median over replicates of the replicate's q-quantile in the bin, lo and hi the pi_level interval of those quantiles across replicates (the prediction interval of the quantile, not a confidence interval of any data), mc_se the Monte Carlo standard error of median. n is the median number of usable values per replicate, n_rep the number of replicates with a defined quantile, n_failed the total number of excluded non-finite values and n_blq the total number of values below lloq over all replicates.
  • observed: nothing, or rows (bin, bin_lo, bin_hi, t_mid, q, value, n, n_failed, n_blq) of the observed quantiles (diagnostic only).
  • endpoint, q, pi_level, replicates, seed, value, blq, n_failed (all excluded simulated values), n_unbinned (observed values in no bin).

Iterating, length and indexing act on rows.
